# ReliefConnect

A Disaster Relief Coordination System designed to help coordinate emergency response, relief operations, resources, and assistance during disasters.

## Features

- 🚨 Report disasters and emergencies
- 🏕️ Find and coordinate relief camps
- 📦 Access disaster-relief resources
- 📞 Request emergency assistance
- 👤 User and admin login
- 📊 Disaster response coordination dashboard

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI

## Run Locally

Clone the repository:

```bash
git clone https://github.com/archit-sahu/Disaster-Relief.git

Go into the project:

cd Disaster-Relief

Install dependencies:

npm install

Start the development server:

npm run dev

The application will be available at:

http://localhost:8080
